## ☕ MODULO 1: Programmazione ad Oggetti (OOP) in JAVA

### 1. Fondamenti dell'OOP e Classi
- [ ] **Il paradigma orientato agli oggetti:** concetto di Classe e Oggetto (istanza)
- [ ] **Stato e comportamento:** Attributi (campi) e Metodi
- [ ] **Costruttori:** costruttore di default, costruttori sovraccaricati, costruttore di copia
- [ ] **Incapsulamento e *Information Hiding*:**
  - [ ] Modificatori di visibilità (`private`, `public`, `protected`)
  - [ ] Metodi di accesso e modifica: *Getter* e *Setter*
- [ ] **Overloading dei metodi** (sovraccarico)

### 2. Ereditarietà e Polimorfismo
- [ ] **Ereditarietà:** estensione di classi (`extends`), superclasse e sottoclassi
- [ ] **Riuso del codice** e gerarchie di classi
- [ ] **Overriding dei metodi** (sovrascrittura) e uso della parola chiave `super`
- [ ] **Polimorfismo:** *binding* dinamico, tipo statico vs tipo dinamico
- [ ] **Classi astratte e/o Interfacce** (cenni e differenze funzionali)

### 3. Strutture Dati Dinamiche e Gestione Dati
- [ ] **Le collezioni in Java:** introduzione al concetto di struttura dati dinamica
- [ ] **La classe `ArrayList`:**
  - [ ] Dichiarazione, inizializzazione e metodi principali (`add`, `get`, `set`, `remove`, `size`, `clear`)
  - [ ] Scansione tramite cicli `for` standard e cicli `for-each`
- [ ] **ArrayList di Oggetti:** gestione di elenchi e collezioni di istanze personalizzate
- [ ] **Algoritmi su collezioni di oggetti:** ricerca per attributo, inserimento, cancellazione, ordinamento

### 4. Flussi di Input/Output e File di Testo
- [ ] **I flussi di I/O (Stream)** in Java
- [ ] **Gestione dei file di testo (`.txt`, `.csv`):**
  - [ ] Scrittura sequenziale su file (`FileWriter`, `PrintWriter` o `BufferedWriter`)
  - [ ] Lettura sequenziale da file (`Scanner` o `BufferedReader`)
- [ ] **Parsing dei dati:** separazione dei campi (es. tokenizzazione CSV) per istanziare oggetti da file
- [ ] **Gestione base delle eccezioni:** blocchi `try-catch` per la gestione di errori di I/O

## 🐍 MODULO 2: Fondamenti del Linguaggio PYTHON

### 1. Basi del Linguaggio e Sintassi
- [ ] **Caratteristiche di Python:** linguaggio interpretato, tipizzazione dinamica, leggibilità e indentazione
- [ ] **Ambiente di sviluppo:** installazione/configurazione IDE (es. VS Code, PyCharm, IDLE) ed interprete
- [ ] **Elementi di base:** variabili, tipi di dato primitivi (`int`, `float`, `str`, `bool`), input/output (`input()`, `print()`)
- [ ] **Operatori:** aritmetici, relazionali e logici (`and`, `or`, `not`)

### 2. Strutture di Controllo e Iterazione
- [ ] **Strutture di selezione:** costrutto `if`, `elif`, `else`
- [ ] **Strutture cicliche:**
  - [ ] Ciclo indefinito `while`
  - [ ] Ciclo definito `for` con la funzione `range()`
  - [ ] Istruzioni di controllo ciclo: `break`, `continue`

### 3. Modularità e Strutture Dati
- [ ] **Funzioni:** definizione (`def`), parametri di input, valore di ritorno (`return`), visibilità delle variabili
- [ ] **Moduli e librerie standard:** importazione (`import`) e uso di moduli predefiniti (es. `math`, `random`)
- [ ] **Strutture dati native:**
  - [ ] Liste (`list`): creazione, indicizzazione, slicing, metodi nativi
  - [ ] Tuple e/o Dizionari (`dict`): cenni di base su chiavi-valori

## 💻 MODULO LABORATORIO (Attività Pratiche)

- [ ] **Laboratorio Java – OOP base:** implementazione di classi con attributi privati, costruttori, getter/setter
- [ ] **Laboratorio Java – Ereditarietà:** creazione di progetti con superclassi e sottoclassi, verifica dell'overriding
- [ ] **Laboratorio Java – Collezioni:** gestione software di un archivio dati in memoria tramite `ArrayList<Oggetto>`
- [ ] **Laboratorio Java – Persistenza:** salvataggio e caricamento dello stato degli oggetti su file di testo
- [ ] **Laboratorio Python – Scripting:** sviluppo di algoritmi procedurali, calcoli matematici, gestione stringhe e liste
- [ ] **Documentazione e Stile:** convenzioni di naming, commenti al codice, leggibilità e robustezza
